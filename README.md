# Tech Fest – Event Management System

A high-performance, full-stack event management platform built on an edge-first serverless architecture. Tech Fest allows organizers to effortlessly host, manage, and scale tech fests, keynote sessions, speaker profiles, and attendee registrations with ultra-low latency globally.
